# Backlog archive (optional local copies)

This folder can hold **local** copies of long-form groomed exports (e.g. full-detail markdown) for historical § references (e.g. Resolved ticket citations). **Do not commit** those exports — they are listed in `.gitignore`.

**Day-to-day groomed backlog** is **not** stored in this repository. Keep it outside the repo (e.g. under your workspace downloads or a personal notes path).

The **canonical execution/backlog for prioritization** remains a **local artifact**, not `docs/ai-minions-backlog-groomed.md` in git.
